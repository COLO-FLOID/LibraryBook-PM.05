# LibraryBook

## Описание проекта

LibraryBook — информационная система для библиотеки, разработанная в рамках учебной практики по ПМ.05 «Проектирование и разработка информационных систем».

Система предназначена для автоматизации процесса бронирования книг. Пользователи могут регистрироваться в системе, просматривать каталог доступных книг, создавать заявки на бронирование и оставлять отзывы. Администратор осуществляет контроль заявок и изменяет их статусы.

---

## Тестовые учетные записи

### Администратор

```text
Логин: Admin
Пароль: !admin12345
```

Права:
- просмотр всех заявок;
- изменение статусов заявок;
- удаление заявок.

### Пользователь

```text
Логин: testuser
Пароль: qazqaz123
```

Права:
- просмотр каталога книг;
- создание заявок на бронирование;
- просмотр собственных заявок;
- добавление отзывов.

## Запуск проекта

1. Установить Python и XAMPP.

2. Запустить Apache и MySQL в XAMPP.

3. Создать базу данных:

```sql
library_db
```

4. Импортировать файл:

```text
db/library.sql
```

5. Установить зависимости:

```bash
pip install flask
pip install flask-cors
pip install pymysql
pip install werkzeug
```

6. Запустить приложение:

```bash
python app.py
```

7. Открыть в браузере:

```text
http://127.0.0.1:5000
```

## Особенности проекта

- Хеширование паролей пользователей;
- Разделение доступа по ролям;

- Использование внешних ключей в базе данных;

- Реализация CRUD-операций для заявок.
